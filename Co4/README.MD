# CO4_AT1

## Question 27 – Longest Palindromic Subsequence

### Problem
Given a string, find the length of the longest subsequence that is also a palindrome.

### Algorithm
Dynamic Programming is used to solve the problem.

### Complexity
- Time Complexity: O(n²)
- Space Complexity: O(n²)

### Sample Input
BBABCBCAB

### Sample Output
Length = 7
